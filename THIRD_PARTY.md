# Upstream provenance

Selected instructions and patterns adapted from https://github.com/vercel-labs/marketing-team-eve-template at commit `f4a9309de0c03b4a42699687f6ae87dd86a913d2`.

Sources: social-media-coordinator/instructions.md; lib/writing-quality/skill.ts and config.ts; lib/content/tools.ts; lib/artifacts/tools.ts. Adaptations: Facebook/Instagram instead of Typefully platforms, read-only brand context, private Convex persistence, bounded independent review, and automatic publication through the existing publisher. The root social agent replaces the template's general marketing-team router. No upstream auto-update is configured.

Runtime: eve 0.57.0, pinned independently of the template's 0.39.x API. Uses existing npm, ESLint and TypeScript settings instead of adopting the template toolchain.
